# 우유마켓

동네 우유 가게의 작은 온라인 주문 앱입니다. 상품 여섯 개, 장바구니, 주문, 주문 내역이 전부입니다.
[우유팩](https://uyoopack.com)에서 기획과 개발이 어떻게 이어지는지 직접 해 보기 위한 **튜토리얼용 프로젝트**입니다 —
작지만 진짜 돌아가고, 고쳐도 되고, 언제든 처음으로 되돌릴 수 있습니다.

```bash
pnpm install
pnpm dev        # http://localhost:3100
pnpm test       # 규칙(장바구니·주문)의 단위 테스트
```

Next.js 16 · React 19 · Tailwind 4. 데이터는 `data/store.json` 파일 하나에 쌓이고 첫 실행에 만들어집니다.

## 어디에 무엇이 있나

| 파일 | 하는 일 |
|---|---|
| `src/lib/catalog.ts` | 상품 여섯 개와 처음 재고 |
| `src/lib/cart.ts` | 장바구니 규칙 — 담기·수량·빼기, 소계·배송비·총액 |
| `src/lib/orders.ts` | 주문 규칙 — 주문 확정과 재고 차감 |
| `src/lib/store.ts` | 저장소(JSON 파일). DB 로 바꾸는 자리 |
| `src/app/` | 화면 셋 — 상품 · 장바구니 · 주문 내역 |

규칙은 순수 함수이고 화면과 저장소를 모릅니다. 테스트는 규칙에만 걸려 있습니다.

## 우유팩 튜토리얼

1. **우유팩에서 튜토리얼 프로젝트를 만듭니다.** 조직 표지의 `튜토리얼 프로젝트 만들기` 를 누르면 이 앱의 명세가 든 프로젝트가 생깁니다.
   요구사항 몇 개는 이미 완료 보고가 있고(이 코드가 그것입니다), 둘은 아직 코드에 없어 열린 작업으로 보입니다.
   문서 머리의 안내가 아래 순서를 그대로 보여 주고, 필요한 명령을 복사해 줍니다.
2. **이 저장소를 내 것으로 만듭니다.** 안내의 `GitHub 에서 내 저장소 만들기` 를 누르거나 이 페이지의 `Use this template` 로
   새 저장소를 만들고, 내 컴퓨터로 클론합니다.
3. **Claude Code 를 우유팩에 연결합니다.** 저장소 안에서 `claude` 를 열고, 우유팩 프로젝트 설정의 연결 카드가 알려 주는
   `claude mcp add …` 한 줄을 실행한 뒤 "우유팩 어댑터를 설치해 줘" 라고 말하면 Claude Code 가 `get_setup_plan` 으로 필요한 파일을 씁니다.
4. **작업을 맡깁니다.** 우유팩 문서의 `개발 보기` 에서 `쿠폰 코드` 작업을 보고, Claude Code 에게 "TSK-… 작업을 해 줘" 라고 합니다.
   Claude Code 는 요구사항을 읽고(`Tell the user` 줄을 옮깁니다), 구현하고, 완료 보고를 올립니다. 문서의 `구현 위치` 가 바뀝니다.
5. **기획을 하나 더합니다.** 문서 바닥의 입력 칸에 "재고가 3개 이하면 상품 카드에 '곧 품절' 을 보여 주고 싶다" 처럼 쓰면 기획 대화가
   열리고, 답해 가면 요구사항 초안이 문서에 찹니다. 확정하면 작업이 생깁니다.
6. **버그를 신고합니다.** 흰우유를 12개 담아 보세요 — 딱 3만 원인데 배송비가 붙습니다. 명세는 "3만 원 이상이면 무료" 입니다.
   입력 칸에 "3만 원어치 담았는데 배송비가 붙어요" 라고 쓰면 버그 흐름이 열립니다.
7. **처음으로 되돌립니다.** 저장소는 `scripts/reset.sh`, 우유팩 프로젝트는 설정의 `튜토리얼 다시 만들기` 입니다.

## 되돌리기

```bash
scripts/reset.sh
```

템플릿의 `main` 으로 강제로 맞추고, `claude/` 브랜치와 열린 PR 을 닫고, 실행 데이터를 지웁니다. 어댑터 설치 파일(`.uyoopack/`·`.mcp.json`·
`.claude/`·`CLAUDE.md` 의 관리 구역)도 함께 사라집니다 — 설치가 튜토리얼의 한 단계이기 때문입니다.

## 범위 밖

결제·회원·상품 관리 화면은 없습니다. 주문은 확정까지만이고 취소는 아직 없습니다(그것이 열린 작업 중 하나입니다).
